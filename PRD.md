# PRD.md — SeaStreams Product Requirements Document

## 1. Visual Design System (Derived from `docs/ui-references/`)
- **Theme:** Deep dark theme (`#000000` default background, `#161A23` surface cards, crisp white `#FFFFFF` primary text, `#A0A8B8` secondary text, `#E5E9F0` high-contrast pill focus states). Selectable background theme swatches in Settings: `#000000` (default), `#171535`, `#351529`, `#351515`, `#153535`, and `#151F35`.
- **Top Navigation Bar (`home-hero.jpg`, `home-catalogs.jpg`):**
  - **Top-Left:** Active profile circular avatar + live system clock in 12-hour `h:mm a` format (e.g. `12:15 AM`, `Locale.US`), never 24-hour time. All user-facing clock times across the app use this 12-hour format.
  - **Top-Right:** Rounded translucent pill container holding: Search (magnifying glass icon), `Home`, `Movies`, `TV Shows`, `Library`, and Settings (gear icon). *(Note: When an age-restricted Kids profile is active, `Movies` and `TV Shows` tabs are hidden).*
  - **Back Button Navigation:** Pressing Remote `Back` while browsing any Home screen content row moves D-pad focus directly to the Top Navigation Bar, defaulting focus onto the `Home` pill.
- **Global Edge-Stop-Then-Wrap Rule (applies to every screen, including all Milestone 4+ screens):** Focus never wraps automatically while a direction key is held down.
  - **Held key (`KeyEvent.nativeKeyEvent.repeatCount > 0`):** Focus stops and stays on the last item of a horizontal row (`Right`) or the bottom-most row/element of a page (`Down`). Auto-repeat events at the edge are consumed so focus neither wraps nor escapes elsewhere.
  - **Fresh press at the edge (`repeatCount == 0`):** Only when focus is *already* on the last item of a row (or the bottom-most row of a page) and the user presses that same direction again as a new key press does focus wrap: `Right` → item #1 of the row; `Down` → the top of the page.
  - Implementation: shared `Modifier.onDpadEdgeWrap(key, wrap)` in `ui/theme/FocusModifiers.kt`; new rows/grids/pages must use it rather than hand-rolled wrap handlers.
  - **Key-Up / Phantom Click Guard (Global):** Opening any overlay, HUD, or modal via `DPAD_CENTER`/`Enter` (`KeyDown` or `onLongClick`) must consume or ignore the trailing `KeyUp` event from that same physical press so newly focused controls (e.g., the Player HUD `Play/Pause` button or the 1st item in a stream selection modal) never fire an accidental click on key release. Shared via `Modifier.ignoreInitialKeyUp()` in `ui/theme/FocusModifiers.kt`.
- **Watched Artwork Indicator (Global):** Whenever a movie, TV show, or episode is marked as watched (`>= 90%` progress or manually marked watched), display a crisp white checkmark (`Icons.Rounded.Check` / `#FFFFFF`) inside a subtle dark translucent circular pill at the **top-right corner** of its artwork (with uniform `6dp–8dp` corner padding so it remains legible over bright posters/stills). Do **not** render a bottom progress line for completed/watched items (reserve bottom progress bars strictly for active, in-progress items `< 90%` in `Continue Watching` or partially watched episodes).

## 2. Onboarding & Profiles (Max 5 Profiles)
- **Startup Splash Screen (precedes the Profile Gate):** Every cold launch shows a native Jetpack Compose splash (`SeaStreamsSplashScreen`) before `ProfileCreateScreen` / `ProfileSelectScreen`.
  - **System launch window:** Pure black `#000000` window background with no system splash icon (Android 12+ `windowSplashScreenAnimatedIcon` is transparent), so there is no duplicate centre-icon flash before the Compose splash appears.
  - **Layout:** Pure black `#000000` full-screen background (independent of the user's Settings background colour). Centred row: the SeaStreams icon (`R.drawable.ic_seastreams_icon`, `96dp`) then `24dp` gap then the lowercase wordmark `seastreams` in white Fredoka SemiBold (`R.font.fredoka_semibold`, `64sp`), each letter its own `androidx.tv.material3.Text` with font padding disabled. Because the wordmark is all x-height letters (no ascenders/descenders), its ink sits below the centre of its line box. The icon is shifted `14dp` down so its top corner sits above the `s`, its bottom corner below, and its right-hand tip near the `s` waist (`docs/ui-references/1280x720.png`).
  - **Pop-in and bobbing animation (one-shot, no loop):** The splash holds pure black for `420ms`, so the Android TV launch crossfade and startup work finish before any letter moves. Letters then appear left-to-right over `2840ms` (`110ms` stagger, `1850ms` each; `9 × 110ms + 1850ms = 2840ms`). In the first 26% of its life, each letter fades in and rises boldly out of the water from `0.25x` / `18dp` below / `-14°` to a crest (`1.12x`, `13dp` up, tilted ~`10°` right). It then bobs like a float on a slow swell (dips ~`7.8dp` below the baseline, rises ~`2.7dp` back above), rocking side-to-side (~`6°`, then ~`2°`) with a slight lag, and settles exactly flat.
  - **Hold & exit:** After the motion settles (`420ms + 2840ms`), the still wordmark holds for ~`90ms`: the splash stays up for at least `3350ms` from first frame *and* until the initial profile/TMDB-key gate state has loaded (`AppGate != Loading`), then hands off to the Profile Gate. It shows once per process: it is not replayed after configuration changes or when returning from Home to the profile switcher.
  - **Profile Gate preload:** When profiles already exist (`AppGate.Ready`), the splash creates the Profile Gate's ViewModel, so the child-safe featured backdrop (same `GetProfileGateBackdropUseCase` filtering, rule 6) is fetched and decoded into Coil's memory/disk cache behind the splash. `ProfileSelectScreen` then draws its artwork on its first frame with no empty or loading flash. The preload does not run during first-run onboarding, because the Kids-aware filter must see the real profile list.
  - **Input:** Remote `Back` is consumed during the splash (no accidental exit); the splash has no focusable elements, so no D-pad focus is set until the Profile Gate draws.
- **Profile Gate (`profiles.jpg`):** On startup, if no profile exists, launch directly into Profile Creation. If profiles exist, display the vertical "Choose a Profile" selector on the left with full-bleed featured backdrop art on the right, plus an edit pencil icon and `+` button (up to 5 profiles).
  - **Child-Safe Profile Gate Artwork:** Backdrop artwork displayed on `ProfileSelectScreen` must never pull from Adult `Continue Watching` history and must exclude all **Horror** (TMDB genre ID `27`) and **Romance** (TMDB genre ID `10749`) titles (plus `Thriller` `53` and `Crime` `80`), while enforcing a strict family-safe certification ceiling (`PG` / `TV-PG`, `allowUnrated = false`) via `AgeRestrictionEngine` whenever at least one Kids/age-restricted profile exists on the device (or capping at `PG-13` / `TV-14` with `allowUnrated = false` if only Adult profiles exist). This is re-evaluated live: the moment a Kids profile is added (or a profile is switched to Kids), any artwork chosen under the Adult-only ceiling is hidden and a stricter backdrop is fetched. If that fetch fails, the dark background stays; the adult artwork is never shown again.
- **Mandatory TMDB Key & Web Portal Input:** During first profile creation, the user must enter a valid TMDB API key (validated via a test call to `/configuration`) before proceeding. Users can type via on-screen keyboard OR scan a QR code / visit the local LAN IP (`http://<tv-ip>:8765`) to type the API key and profile name from a phone/PC browser.
- **Profile Age Restrictions:**
  - Profiles can be standard (Adult) or Kids (Age-Restricted with max certification ceiling, e.g., `G`, `PG`, `PG-13` / `TV-Y`, `TV-Y7`, `TV-G`, `TV-PG`, plus a toggle to `Allow/Disallow Unrated Items`).
  - **Hard Filtering:** On Kids profiles, any movie/show outside the allowed rating—or unrated when disallowed—is stripped at the data layer even if returned by an external Stremio addon or MDBList.

## 3. Home Screen Architecture
- **Adult Profile Home Layout:**
  1. **Hero Carousel (`home-hero.jpg`):** Large rounded-corner featured card spanning screen width. Pools the first 15 items of `https://mdblist.com/lists/official/movies/justwatch-streaming-charts` and the first 15 of `https://mdblist.com/lists/official/shows/justwatch-streaming-charts` (30 total, de-duplicated), shuffles them, and caps the carousel at 10 items per Home screen load (only titles with backdrop art qualify). Horizontal D-pad scrolling cycles items; displays logo/title, match/rating %, year, genres, certification, runtime, truncated synopsis, and a focused `View Details` pill button.
     - **Focus Ring:** While the hero holds D-pad focus, the card shows the same crisp `3dp` `#E5E9F0` focus border used by focused catalog cards (shared `FocusBorderWidth` / `Modifier.focusRing` in `ui/theme/FocusModifiers.kt`), drawn on the hero's own rounded shape.
     - **Continuous 5-Second Auto-Advance:** The hero advances to the next item every 5 seconds, wrapping from item #10 back to #1, for as long as Home is on screen — including while focus is on the Top Navigation Bar or the catalog rows below. Only direct interaction with the hero (Left/Right on the hero card, or pressing its button) restarts the 5-second countdown. The timer pauses when Home leaves the foreground (`ON_PAUSE`/`ON_STOP`) or the user navigates to another screen.
  2. **Continue Watching (`home-genres-continue.jpg`):** Horizontal row of the user's last 10 in-progress movies/episodes with progress bars and season/episode badges (`S7:E10`). Clicking an item either starts playback immediately (if *Auto-play from Continue Watching* is ON) or opens its Details page (if OFF).
     - **Long-Press Action Menu (`onLongClick`):** Pressing and holding `OK`/`Enter` on a `Continue Watching` card opens the shared centered D-pad action menu (same focus trap, `Down` wrap, and `Back` dismiss behavior as `EpisodesScreen` in §6) with two options:
       - `Remove`: Hides/dismisses the item from the `Continue Watching` row without altering its watch progress or watched status (`WatchProgressDao` record remains intact). If the user plays that movie or episode again later, it reappears in `Continue Watching` as normal.
       - `Clear progress`: Removes the item from `Continue Watching` **and** marks that specific movie or single episode as unwatched by deleting its progress record in `WatchProgressDao` (for TV shows, only the specific focused episode is cleared, not other episodes or the whole series).
     - **Post-Action & Dismiss Focus Restoration:**
       - Pressing `Back` dismisses the menu without making changes and returns D-pad focus to the exact `Continue Watching` item that opened it.
       - Selecting either `Remove` or `Clear progress` dismisses the menu, removes the card from the row, and returns D-pad focus to the `Continue Watching` row onto the **next item to the right** (or onto the **previous item to the left** if the removed item was the last item in the row; if the row becomes empty, focus moves cleanly to the next available row below or the `HeroCarousel` above).
  3. **Most Watched Movies:** Horizontal row pulling from `https://mdblist.com/lists/official/movies/most-watched-week`.
  4. **Most Watched Shows:** Horizontal row pulling from `https://mdblist.com/lists/official/shows/most-watched-week`.
  5. **Metadata Addon Catalogs:** Any catalogs exposed by enabled Stremio metadata/catalog addons populate exclusively on the `Home` screen directly beneath `Most Watched Shows` (in installed addon order, using the standard `ExpandingCatalogRow` with 20-item cap + `View More`).
- **Kids Profile Home Layout:**
  1. **Kids Hero Carousel:** Pools the first 15 entries of `https://mdblist.com/lists/snoak/trending-kids-movies` and the first 15 of `https://mdblist.com/lists/tvgeniekodi/trending-kids-tv-shows` (30 total), strictly filtered through `AgeRestrictionEngine` against the profile's ceiling, shuffles them, and caps the carousel at 10 items per Home screen load. Same focus ring and continuous 5-second auto-advance as the Adult hero.
  2. **Continue Watching:** Last 10 watched items for that Kids profile.
  3. **Fixed Kids Rows:** `Trending Kids Movies`, `Trending Kids Shows`, `Latest Family Movies` (`kep084/latest-family-movies`), and `Latest Family Shows` (`kep084/latest-family-shows`), filtered strictly by the profile's age ceiling.
  4. **Metadata Addon Catalogs:** Any catalogs exposed by enabled Stremio metadata/catalog addons populate on `Home` directly beneath `Latest Family Shows`, strictly filtered through `AgeRestrictionEngine` against the profile's ceiling.

## 4. Expanding Catalog Rows & "View More" Grid
- **Expanding Card Behavior (`catalog1.jpg`, `home-catalogs.jpg`):** On `Home`, `Movies`, and `TV Shows` tabs, every horizontal row always shows exactly one wide 16:9 backdrop card (with title logo) while its other items stay vertical 2:3 posters. That wide card is item #1 by default, or the last item focused in that row: moving D-pad focus along a row smoothly animates the newly focused item from poster to 16:9 (and the previous one back to a poster), and the card **stays wide** when focus leaves the row with `Up`/`Down` (to another row or the Top Navigation Bar). Card height is identical in both shapes, so rows never change height as focus moves between them. Only the single card that currently holds D-pad focus draws the `3dp` `#E5E9F0` focus ring; the wide cards of unfocused rows show no ring. The focused row shows the rating %, year, genre, runtime, and synopsis below its wide card. A row's wide card resets to item #1 when its catalog data refreshes or when returning from that row's `View More` screen. The `View More` card is wide only while it holds focus; leaving the row from it leaves the row's last media item wide instead.
- **Catalog Row Scroll Speed:** Horizontal D-pad scrolling across catalog rows on `Home`, `Movies`, and `TV Shows` is governed by the `Catalog row scroll speed` setting (`Slow` [default], `Medium`, `Fast`):
  - **Slow (Default):** Uses an extended, fluid eased animation curve (`~480ms` `FastOutSlowInEasing` / low-stiffness critically damped spring) for both the `TvLazyRow` horizontal viewport scroll (`animateScrollToItem` / custom `BringIntoViewSpec` scroll animation) and the synchronized `2:3 -> 16:9` card width expansion (`animateDpAsState`), ensuring posters visibly and smoothly glide across the row as the user steps through items.
  - **Medium:** Uses a balanced mid-speed eased curve (`~280ms` `FastOutSlowInEasing`) halfway between `Slow` and `Fast` for both row translation and card expansion.
  - **Fast:** Preserves the original snappy transition speed (`~130ms` / default Compose scroll spec) for immediate rapid-fire D-pad navigation.
- **Row Cap & Looping (`catalog2.jpg`):** Each horizontal row (Home, Movies, and TV Shows, including metadata addon catalogs and Kids rows) displays up to 20 items. If the source catalog has >20 items (for TMDB `/discover` and `/trending`: `total_pages > 1`, so rows only fetch `page=1`), a `View More` (`>>`) card appears at position 21. Pressing `Right` past the end of the row (past `View More`, or past the last item if ≤20 items) wraps focus smoothly back to item #1, following the §1 Edge-Stop-Then-Wrap Rule (holding `Right` stops at the end; a fresh `Right` press there wraps).
- **View More Screen (`view-more.jpg`):** Clicking `View More` opens a vertical 5-column poster grid displaying up to 100 items from that catalog (standard 2:3 posters only, no 16:9 expansion).
- **Inline Catalog Row Trailer Auto-Play:** On `Home`, `Movies`, and `TV Shows` tabs (excluding `HeroCarousel`, `Continue Watching`, `View More`, `Search`, and `Library`), when *Auto-Play Trailers* is enabled in Settings and D-pad focus rests continuously on a media item's expanded 16:9 card for the configured delay (`1s–7s`, default `2s`), the item's official YouTube trailer resolves via `NewPipeExtractor` and plays inside that 16:9 artwork frame (zoomed to fill the frame without player controls, keeping the `3dp` `#E5E9F0` focus ring and metadata below intact).
  - **Muted Indicator:** When *Mute Auto-Play Trailers* is enabled (`volume = 0f`), display a small white speaker-with-slash icon (`Icons.AutoMirrored.Rounded.VolumeOff`) in the top-right corner of the 16:9 artwork frame (offset cleanly to the left of the top-right watched checkmark badge if the item is also watched).
  - **Cancellation & Silent Failure (Zero YouTube Fallback):** Moving D-pad focus away, holding a direction key (`repeatCount > 0`), navigating to another screen, pausing/stopping the app, or encountering any stream extraction or playback failure immediately stops playback and reverts cleanly to the static 16:9 backdrop artwork as if trailers were disabled. Catalog row trailer failures must **never** fall back to the external YouTube app.

## 5. Movies & TV Shows Tabs (TMDB Discover)
- **Movies Tab:** `Popular Movies` plus toggleable streaming rows (`Netflix` ID 8, `Amazon Prime` ID 9, `Disney+` ID 337, `HBO Max` ID 1899, `Hulu` ID 15, `Apple TV+` ID 350, `Paramount+` IDs `2303|531|2616`, `Peacock` ID 386) using:
  `GET https://api.themoviedb.org/3/discover/movie?with_watch_providers={ID}&watch_region=US&with_watch_monetization_types=flatrate&sort_by=popularity.desc&include_adult=false&language=en-US&page=1`
  `Paramount+` ORs its US provider IDs (`with_watch_providers=2303|531|2616`: `2303` Paramount Plus Premium, `531` legacy Paramount+, `2616` Paramount+ Essential) on both `/discover/movie` and `/discover/tv`, because TMDB moved US Paramount+ titles off `531`, which alone returns only a few obscure international titles. Saved provider toggles are keyed by the provider's name, not its TMDB IDs.
- **TV Shows Tab:** `Popular Shows` plus the same toggleable streaming providers using `/discover/tv`.
- **Layout & Focus Order (both tabs):** `Popular Movies` / `Popular Shows` is the first content row directly below the Top Navigation Bar (`Down` from the nav bar lands on its item #1), followed by every enabled streaming-provider row (custom MDBList rows and metadata addon catalogs do not appear on `Movies` or `TV Shows`). The `Streaming services` label and its 8 toggleable provider pills sit at the very **bottom** of the page, with bottom padding so focused pills are never clipped at the viewport edge. Toggling a pill shows/hides its row above while focus stays on the toggled pill. The pill row is the page's bottom-most element and owns the §1 `Down` edge-stop-then-wrap (held `Down` stops there; a fresh `Down` wraps to the top of the page); `Left`/`Right` moves across the pills, with the last pill following the §1 `Right` wrap.
- **Caching & Rate Limits:** Cache `/discover` and `/external_ids` responses locally for 6–12 hours. Retry HTTP `429` responses with exponential backoff. Never batch-fetch `/external_ids` on catalog load.

## 6. Item Details & Episodes Screens
- **Details Screen (`movie-page.jpg`, `show-page.jpg`):**
  - Full-bleed edge-to-edge backdrop artwork with left vignette gradient.
  - Left column displays: Title/Logo, rating %, release year, up to 2 genres, age certification badge, duration, 3-line synopsis, and cast list.
  - Vertical action button stack: `Play` (high-contrast white pill), `Trailer` (ignores all inline catalog trailer auto-play, mute, and delay settings; resolves the official YouTube trailer stream via `NewPipeExtractor` and plays full-screen with audio enabled inside the built-in Media3 ExoPlayer without recording watch progress, falling back silently to external YouTube only if stream extraction fails), `More episodes` (TV shows only), `Shuffle` (TV shows only — plays a random episode across available seasons), and `Add to library` / `Remove from library`.
  - **Library Button State & Duplicate Guard:** When an item is already saved in the active profile's library, the action button dynamically displays `Remove from library` instead of `Add to library`, and clicking it removes the item from the library. Library insertion at the repository/DAO layer must be idempotent (`OnConflictStrategy.IGNORE` / existence check) so attempting to add an already-saved item never inserts duplicates or causes UI glitches, and displays a brief `"Already in library"` toast/snackbar.
  - **Play / Resume Button Long-Press:** When *Auto-play top stream* is enabled, a normal `OK`/`Enter` click on `Play` (or `Resume`) auto-plays the top stream, whereas pressing and holding (`onLongClick`) bypasses auto-play and opens the stream selection modal with initial focus on the 1st stream result. Releasing the held `OK`/`Enter` button must never trigger an accidental click on that 1st stream result.
  - **Exact Focus Restoration on Back:** Pressing Remote `Back` to exit `DetailsScreen` must return D-pad focus to the exact originating item/card/button from which `DetailsScreen` was opened (`Home` hero or catalog row item, `Movies`, `TV Shows`, `View More`, `Search`, or `Library`).
  - Opening this screen triggers the lazy fetch of `/external_ids` (IMDb ID) so Stremio stream addons can be queried.
- **Episodes Screen (`EpisodesScreen.kt`):**
  - Left pane: Show title, metadata, and vertical Season selector pills (`Season 1`, `Season 2`, etc.).
  - Right pane: Vertical list of episodes showing episode number badge, 16:9 still thumbnail (blurred if unwatched and *Blur Unwatched Thumbnails* is enabled), episode title, air date, runtime, and synopsis, displaying the global top-right white checkmark badge on the thumbnail for watched episodes (and a bottom progress bar only for partially watched in-progress episodes).
  - **Long-Press Action Menus (shared behavior):** Pressing and holding `OK`/`Enter` opens a centered, D-pad-focusable action menu over a dimmed screen. Initial focus lands on the first option, focus cannot leave the menu, a fresh `Down` on the last option wraps to the first, and releasing the held `OK` never triggers an option. Remote `Back` dismisses the menu and returns focus to the exact season pill or episode row that opened it; choosing an option also returns focus there (or to the stream modal the option opened).
  - **Season Pill Long-Press (`onLongClick`):**
    - `Mark Season Watched`: unconditionally marks every episode in that season as watched in `WatchProgressDao`, whatever each episode's current state.
    - `Mark Season Unwatched`: unconditionally marks every episode in that season as unwatched (clears its watch progress) in `WatchProgressDao`, even if only some episodes were watched.
    - `Shuffle Season`: picks a random aired episode from that season only and starts playback — auto-playing the top stream when *Auto-play top stream* is enabled, otherwise opening the stream selection modal.
  - **Episode Row Long-Press (`onLongClick`):**
    - `View streams`: bypasses auto-play and opens the stream selection modal for that episode.
    - `Auto-play`: resolves streams and immediately plays the top stream result (regardless of the *Auto-play top stream* setting), honoring the preferred auto-play addon and the configured internal/external player.
    - `Mark watched` / `Mark unwatched`: the label toggles with the episode's current watched status; choosing it updates `WatchProgressDao`, and the watched indicator and thumbnail blur state update immediately.
    - `Mark previous in season watched`: unconditionally marks every episode in that season with `episodeNumber <= selectedEpisode.episodeNumber` as watched.
    - `Mark previous in season unwatched`: unconditionally marks every episode in that season with `episodeNumber <= selectedEpisode.episodeNumber` as unwatched (clears its watch progress), whether that range is all watched or a mix of watched and unwatched episodes.
  - "Watched" means a finished `WatchProgressDao` record (position = duration, which satisfies the `>= 90%` completion rule in §9); "unwatched" deletes the record, as if the episode was never started.

## 8. Stremio Addons, MDBList Library Import & LAN Web Portal
- **Stremio Protocol Support:** Parse `manifest.json` (including `catalogs`, `resources`, and `types`), fetch `/catalog/{type}/{id}.json`, `/stream/{type}/{id}.json`, and `/subtitles/{type}/{id}.json`. Ship with TMDB metadata built-in and OpenSubtitles (or default Stremio subtitle addon) pre-installed and enabled. Metadata addon catalogs render exclusively on `Home` beneath the built-in Home rows.
- **In-App Addon Manager:** Enable/disable and reorder installed addons (addon order also determines the display order of metadata addon catalogs on `Home`).
- **One-Time MDBList Library Import:** Users can import an `mdblist.com` list URL directly into a profile's `Movies` or `TV Shows` Library via the Local Web Portal. This is strictly a one-time batch import: once the list's items are resolved and inserted into `LibraryDao` (ignoring duplicates), SeaStreams does **not** store a subscription, track list changes, or sync future updates.
- **Local Web Portal (QR Code + LAN IP):** Single-page web app served by Ktor on the TV's local IP allowing the user to:
  1. Enter/update TMDB API key & profile fields.
  2. Install Stremio addons via manifest URL, remove, rename, disable, or reorder addons.
  3. Import `mdblist.com` list URLs into a profile's `Movies` or `TV Shows` Library (one-time import with no ongoing list tracking/syncing).

## 9. Playback Engine (Media3 ExoPlayer) & Audio/Subtitle Controls
- **Default & External Players (with Full Watch Progress Sync):**
  - ExoPlayer is default; Settings supports launching streams via any installed external Android video player—listing preset/detected video players (Just Player, MX Player, Vimu, VLC, Kodi, plus any other installed app registered for `video/*` via `PackageManager.queryIntentActivities`) as well as an **Other (System App Chooser)** option using `Intent.createChooser`.
  - Launches via `ActivityResultContracts.StartActivityForResult` with `ACTION_VIEW` (`video/*`), passing saved resume positions (`position` / `startfrom` extras) and `return_result = true`.
  - **External Player Progress Preservation:** Parse returned `position`, `duration`, and `end_by` result extras (`position / duration` calculation so exiting partway saves the exact resume timestamp without falsely marking the item watched). If any external player omits position extras on exit, fall back to safe elapsed-time estimation or preserve prior progress—never corrupting or wiping watch status.
  - **In-App Trailer Playback (`PlaybackRequest.Trailer` & Inline Row Previews):**
    - **Details Screen (`PlaybackRequest.Trailer`):** Clicking `Trailer` on `DetailsScreen` always plays full-screen with audio enabled inside the built-in Media3 ExoPlayer (bypassing external player settings and ignoring inline trailer auto-play/mute/delay settings) using adaptive video+audio streams extracted via `NewPipeExtractor` (`MergingMediaSource`). It never writes to `WatchProgressDao`, disables Stremio stream fallback and `autoPlayNextEpisode`, hides Stremio audio/subtitle track pickers and Clean SDH toggles in the OSD, exits automatically back to `DetailsScreen` (restoring D-pad focus to the `Trailer` button) when playback ends, and falls back silently to external YouTube only if stream extraction fails.
    - **Catalog Row Previews (`Home`, `Movies`, `TV Shows`):** Uses a single shared lifecycle-aware `ExoPlayer` instance to play extracted trailers inside the focused 16:9 catalog card after the configured `1s–7s` hover delay (`2s` default), honoring *Auto-Play Trailers* and *Mute Auto-Play Trailers*, showing a top-right white muted speaker icon when muted, recording zero watch progress, and failing silently back to static 16:9 artwork without ever launching external YouTube.
- **Auto-Play, Auto-Next Episode & Stream Fallback:**
  - **Auto-Play Next Episode (Enabled by Default):** Toggle in Settings (`true` by default). When a TV episode finishes (`>= 90%` watched or `end_by == "playback_completion"`), automatically resolve the next episode in sequence, fetch streams, and auto-play the **top stream result** (honoring the preferred auto-play addon setting). Works seamlessly in both internal ExoPlayer and external players (upon receiving the completed `ActivityResult` from the external player; exiting early via `Back` saves progress and cancels auto-next).
  - **Auto-Play Top Stream & Preferred Addon:** Option to auto-play top stream result on manual `Play` click (while long-pressing `Play` still opens the stream list), plus a setting to select *which* preferred addon supplies the top stream.
  - **Automatic Fallback:** If a stream fails to buffer/start or throws a playback error within a configurable timeout (default `5s`, adjustable `1s–10s`), automatically advance to and play the next stream in the list.
  - **Playback Buffer Profile (`DefaultLoadControl`):** Configurable read-ahead buffer size in Settings (`Standard` [~50s / 64 MB], `Large` [2 min / 150 MB], `Max` [5 min / 250 MB], default `Large`) with an elevated rebuffer threshold (`5,000ms` on `Large`/`Max`) so ExoPlayer banks video during high-speed bursts to absorb transient ISP/VPS peering dips without stalling.
  - **Parallel HTTP Range Reader (`ParallelRangeDataSource`):** Configurable parallel HTTP byte-range connection count (`Off (1x)`, `2x`, `3x`, `4x`, default `3x`) for HTTP/HTTPS media streams. Splits sequential reads into concurrent `Range: bytes=start-end` sub-requests (4 MB–8 MB read-ahead ring buffer) using the shared `OkHttpClient`, transparently falling back to single-stream sequential reading if the upstream server omits `Accept-Ranges: bytes` / `206 Partial Content` or for local/non-HTTP URIs.
- **Audio DSP & Sync (Requires Audio Passthrough Toggle):**
  - Toggle to disable HDMI audio passthrough so PCM audio can be processed on-device.
  - **Dialogue Boost:** Off, `+3 dB`, `+6 dB`, `+9 dB`, `+12 dB` center-channel/vocal frequency gain.
  - **Night Mode:** Dynamic range compression evening out loud explosions and quiet speech.
  - **Audio Delay:** Adjustable `-500ms` to `+500ms` (in `25ms` steps) to sync Bluetooth/wireless headphones.
- **Subtitles & HDR:**
  - Global toggle: *Always On* (if available) or *Always Off*.
  - Preferred Subtitle & Audio Language settings: Preferred subtitle language always sorts to the top of the player track list; optional toggle to *Hide non-preferred subtitle languages*.
  - **Clean SDH Toggle:** Regex/parser filter stripping bracketed/parenthetical sound cues (`[SIGHS]`, `(DOOR CREAKS)`, `♪`) and speaker labels (`JOHN:`) from `.srt`/`.vtt` cues in real time.
  - **Subtitle Styling:** Font size, bold, italic, text color, outline/drop-shadow, and background opacity configurable in General Settings (persistent default) AND inside the Player OSD (session-only override that resets when exiting playback).
  - **Convert Dolby Vision Profile 7 to HDR:** Toggle (enabled/`true` by default) that converts or falls back Dolby Vision Profile 7 (`dvhe.07` / `dvh1.07`) video tracks to standard HDR10/base-layer playback for compatibility with displays/devices that do not support Profile 7 FEL/MEL.
  - **HDR White Dimming:** Optional overlay/tone-map luminance cap to dim bright specular whites during HDR10/Dolby Vision playback.
- **Player HUD / OSD Controls & Remote Behavior (`PlayerScreen.kt` & `PlayerOverlayControls.kt`):**
  - **Remote Invocation & Back Behavior:**
    - Pressing `Enter`/`DPAD_CENTER` while media is playing pauses playback and opens the Player HUD without triggering the newly focused `Play/Pause` button when the key is released.
    - Pressing `Up` or `Down` while media is playing keeps playback running and opens the Player HUD.
    - Pressing `Back` while the Player HUD (or any sub-overlay) is visible dismisses the overlay/HUD without stopping playback; pressing `Back` while the Player HUD is hidden exits playback and returns to the previous screen.
  - **Bottom Action Bar Items (Left to Right):**
    1. **Play / Pause:** Dynamic toggle icon reflecting live playback state (`Pause` icon while playing, `Play` icon while paused).
    2. **Next Episode:** Appears only when playing a TV episode (hidden for movies); resolves and plays the next sequential episode's top stream.
    3. **Subtitles:** Opens a non-blocking player overlay to switch subtitle tracks (internal + Stremio addon tracks, honoring preferred language sorting and *Hide non-preferred languages*), toggle *Clean SDH*, and adjust **session-only Subtitle Styling** (resets on player exit without overwriting General Settings).
    4. **Subtitle Timing Offset (`-  0.0s  +`):** Appears **only** when an external subtitle track is active (hidden when subtitles are off or an embedded track is selected). Displays `-` (slow down / delay subtitles) and `+` (speed up / advance subtitles) flanking the live offset value (`0.0s` default), adjusting in `0.1s` increments across `-60.0s` to `+60.0s` (session-only, resets on playback exit).
    5. **Audio:** Opens a non-blocking player overlay to select audio tracks and adjust **session-only** audio settings (*Dialogue Boost*, *Night Mode*, and *Audio Delay*). Any adjustments made here are strictly session-only—they do not persist to future playback, and General Settings audio values take priority once playback exits.
    6. **Streams:** Opens a non-blocking player overlay listing the resolved Stremio stream candidates for the current movie/episode without stopping or exiting the player, allowing instant live stream switching.
    7. **Episodes:** Appears when playing a TV episode; opens a non-blocking player overlay to browse seasons and episodes of the current show without exiting the player, allowing direct episode selection.
    8. **Info:** Opens an in-player technical metadata overlay displaying technical playback telemetry: selected stream title/source rank (e.g., `Stream #1 of 12`), player engine (`Media3 ExoPlayer`), source filename, video codec, resolution, bitrate, audio codec, channel layout, sample rate, audio language, active subtitle name, subtitle language, subtitle source (`Embedded` or `External`), **live download throughput (`Mbps` rolling 2-second average)**, **active HTTP range connections (`1x`–`4x`)**, and **live buffer health (`buffered seconds` & `buffered MB`)**.
  
  ## 10. General Settings Screen (`settings-example.jpg`)
- **Layout & Visual Style:**
  - Two-column split layout matching `docs/ui-references/settings-example.jpg`.
  - **Left Pane (~30% width):** Centered gear icon above the bold `Settings` title.
  - **Right Pane (~70% width):** Vertically scrolling list grouped under uppercase section headers (`ADDONS & PORTAL`, `UI & APPEARANCE`, `PLAYBACK`, `AUDIO`, `SUBTITLES`, `LIBRARY`). Each row is a wide pill-shaped card containing a left icon, primary title, muted subtitle showing the current active value, and either a right chevron `>` (for sub-menus/pickers) or a toggle switch. Focused rows invert to a high-contrast light pill (`#E5E9F0`) with dark text/icons.
- **Visual Background Color Picker:**
  - Located under `UI & APPEARANCE`. Displays visual color swatches (circles/pills — no hex code strings shown to the user) for `#000000` (default), `#171535`, `#351529`, `#351515`, `#153535`, and `#151F35`.
  - **Live Preview on Focus:** Moving D-pad focus onto a color swatch immediately previews that color as the live screen background.
  - **Confirm on Enter / Revert on Back:** Pressing `Enter`/`DPAD_CENTER` confirms the selection and persists it to the **active profile's** `SettingsDataStore` scope; pressing `Back` without confirming discards the preview and restores that profile's previously saved background color. Switching profiles immediately shows the newly selected profile's saved color.
- **Per-Profile Persistence:** Every General Settings preference (UI & Appearance, Playback, Audio and Subtitles items listed below, including the background color, catalog row scroll speed, trailer, buffer/parallel-connection, external player, HDR/Dolby Vision, audio DSP, language and subtitle styling values) is persisted per profile, keyed by `profileId`. Changing a setting on one profile never affects another. A new profile starts from the documented defaults, existing profiles carry over the values they had when the app moved from app-wide to per-profile settings, and deleting a profile deletes its stored settings. Installed Stremio addons, the Web Portal, the TMDB API key and the active-profile selection remain app-wide.

  - **Addons & Portal:** Manage Stremio Addons (enable/disable, reorder, remove) + Open Local LAN Web Portal / QR Code modal.
